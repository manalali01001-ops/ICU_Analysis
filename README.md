# ICU Analysis & Healthcare Funnel Dashboard

An end-to-end healthcare analytics project examining patient flow, intensive care unit (ICU) metrics, and length of stay (LOS) distributions to identify clinical bottlenecks and improve resource allocation.

---

## 📌 Project Overview

Optimizing patient flow through critical care units is essential for hospital operational efficiency and quality of care. This project evaluates patient movement across intensive care stages to understand admission patterns, stay durations, and unit transitions.

---

## 🛠️ Tech Stack & Tools

* **Data Processing & ETL:** Python (`pandas`, `numpy`), Power Query
* **Business Intelligence:** Power BI (DAX, Interactive Dashboards)
* **Data Format:** Structured relational healthcare datasets (`.csv`)

---

## 📊 Key Analysis & Features

* **Healthcare Funnel Analysis:** Maps patient progression across key care units (ICU, PICU, NICU, ER, Home Care) to identify funnel drop-offs and capacity constraints.
* **Length of Stay (LOS) Modeling:** Evaluates LOS distributions across departments to pinpoint high-occupancy drivers.
* **KPI Metrics:** Tracks unit-level admission rates, average stay durations, and patient transition efficiency.
